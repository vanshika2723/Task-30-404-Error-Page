# 🚫 Task 30 – Custom 404 Error Page

A modern, clean, and responsive **404 Error Page** designed using **HTML5 and CSS3**. This project provides a friendly and visually appealing experience when a user tries to access a page that does not exist.

The page includes a large 404 error message, a custom CSS illustration, friendly navigation text, and a button that allows users to return to the homepage.

## 📌 Project Overview

A **404 Error Page** is displayed when a requested webpage cannot be found on a website.

This project focuses on creating a custom alternative to the default browser/server 404 page. Instead of showing a plain error message, the page provides a friendly interface that helps users understand the problem and easily navigate back to the homepage.

## 🎨 Design

The page uses a clean and minimal design with a centered content layout.

The main elements include:

1. Custom CSS illustration
2. Large `404` heading
3. Page-not-found message
4. Friendly explanation
5. Back to Homepage button
6. Error code information

The layout is vertically and horizontally centered to keep the error message easy to understand.

---

## 🪐 Custom Illustration

The illustration is created completely using **CSS** without requiring an external image.

It includes:

- A circular planet
- Planet ring
- Decorative dots
- Floating stars
- CSS gradients
- CSS animations

This helps demonstrate how CSS can be used to create simple visual elements without external assets.

---

## 📱 Responsive Design

The page is responsive and adapts to different screen sizes.

It is designed for:

- 💻 Desktop computers
- 📱 Mobile phones
- 📲 Tablets

CSS media queries are used to adjust the typography, illustration size, spacing, and button layout on smaller screens.
